# ¿Cuánto vale tu voto?

Web estática (carpeta `docs/`, lista para GitHub Pages) que explica el sistema electoral español con ejemplos reales.

Vista previa: configuración «electoral» de `C:\claude\.claude\launch.json` (puerto 8771).

## De dónde sale cada cifra

Resultados oficiales del Ministerio del Interior tal como los recoge Wikipedia (páginas «Results of the … Spanish Congress election» y de cada circunscripción). La descarga directa de infoelectoral.interior.gob.es corta la conexión a los scripts.

- Nacionales: 2015, abril y noviembre de 2019 y 2023 (votos y escaños).
- VOX por provincia 2019 → 2023: tabla resumen por circunscripción.
- Albacete 2023: votos exactos (PP 88.299, PSOE 76.322, VOX 36.750, Sumar 15.834; válidos 221.191).
- Votantes por diputado: censo 2023 (Teruel 106.352 / 3, Madrid 5.224.561 / 37).
- Mayorías absolutas: PSOE 1982 (48,11 %, 202), PSOE 1986 (44,06 %, 184), PP 2000 (44,52 %, 183), PP 2011 (44,63 %, 186); PSOE 1989 (39,60 %, 175).
- Ceuta 2023: PP 12.918, PSOE 11.332, VOX 7.752 (válidos 33.321). Melilla 2023: PP 49,16 %.
- Listas cerradas: artículo 96 de la LOREG (tachar o alterar la papeleta la anula).
- Senado 2023: % de votos y senadores electos (208).
- «Si cada voto valiera igual»: D'Hondt con los votos de toda España, 350 escaños y sin barrera (calculado aparte).
- A Coruña con SALF: escenario inventado, se dice en la página.
